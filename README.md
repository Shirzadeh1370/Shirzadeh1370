# Data Analytics Portfolio | Shirzadeh1370

I build practical analytics projects with **Python (pandas)**, **SQL (SQLite)**, reproducible CSV data, KPI reports, and data visualizations. My interests include business analytics, IT operations, and security analytics.

## Five entry-level data analyst projects

| Project | Business question | Skills |
| --- | --- | --- |
| [01. Retail Sales & Profit](data-analyst-portfolio/01-retail-sales/) | Which product categories and regions drive net sales and margin? | Python, SQL, data cleaning, KPI reporting |
| [02. Subscription Customer Churn](data-analyst-portfolio/02-customer-churn/) | Which customer segments have higher churn? | EDA, segmentation, rates, Python |
| [03. IT Help Desk SLA Dashboard](data-analyst-portfolio/03-helpdesk-sla/) | Where are resolution delays and SLA risks? | Operations analytics, SQL, service KPIs |
| [04. Security Login Event Analytics](data-analyst-portfolio/04-login-security/) | Where are failed-login bursts that deserve investigation? | Log analytics, event aggregation, rule-based flags |
| [05. Seattle Weather Trends](data-analyst-portfolio/05-seattle-weather/) | How do temperature and precipitation vary by month? | Time-series, real public data, SQL, charts |

**Data transparency:** Projects 01–04 use clearly labeled *synthetic, reproducible demonstration data* — not data from an employer, customers, or security system. Project 05 uses historical Seattle weather data derived from NOAA via Vega Datasets; it is not a live forecast.
